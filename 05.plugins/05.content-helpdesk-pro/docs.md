This plugin allows you to display a form to allow customers to submit support ticket in a Joomla article. To use it:

- Go to Extensions -> Plugins, find and enable Content - Helpdesk Pro plugin
- Edit the Joomla article you want to add submit ticket form to, insert the syntax {helpdeskpro}

Now, when you access to the article, you will see a form to allow users to submit ticket (same with [Submit Ticket menu item](/setup/menu-items#submit-ticket)
