On your Joomla website, it is very likely that you will have a Contact Page to allow site visitors/users to send email to contact you. If you want to convert these contact emails to support tickets, you can use this plugin

1. Go to Extensions -> Plugins, find and enable **System - Helpdesk Pro Ticket From Contact Form** plugin
2. Click on the plugin to edit, set **Default Category** parameter to the category which you want the created ticket to be assigned to.
