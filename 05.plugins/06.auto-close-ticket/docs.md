The plugin can be used to automatically close support tickets without any response in a pre-defined number of days. To use this plugin:

1. Go to Extensions -> Plugins, find and enable **System - Helpdeskpro Auto Close Ticket** plugin
2. By default, the plugin will close tickets without response for 14 days. If you want to change it, edit the plugin, change **Number Days** parameter to the value you want.
