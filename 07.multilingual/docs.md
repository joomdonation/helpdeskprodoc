Helpdesk Pro support multilingual. When you use Helpdesk Pro on a multilingual website, you will need to translate the following items to your language:

- Go to Helpdesk Pro -> Categories, click on every category to edit, look at Translation tab and translate the category to allow additional languages.
- Go to Helpdesk Pro -> Messages, look at Translation tab and translate all the messages to allow additional languages
- Go to Helpdesk Pro -> Translation, translate language items to all the languages.
- Go to Helpdesk Pro -> Ticket Priorities, click on every priority to edit, look at Translation tab and translate the category to allow additional languages.
- Go to Helpdesk Pro -> Ticket Statues, click on every Status to edit, look at Translation tab and translate the category to allow additional languages.
- If you use Custom Fields, go to Helpdesk Pro -> Custom Fields, click on every custom field to edit and translate it to all other languages (beside default language) used on your site.
