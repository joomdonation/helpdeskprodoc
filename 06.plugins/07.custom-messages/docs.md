**Helpdesk Pro - Custom Messages** displays messages in the ticket details sidebar on the site and in the administrator area. Use it to share links, reminders, or category-specific instructions. For example, show a link to your invoice guide on billing tickets or display your support hours on every ticket.

## Add a Sidebar Message

1. In the Joomla administrator area, go to **System → Manage → Plugins** and open **Helpdesk Pro - Custom Messages**.
2. Under **Custom Messages**, add a row for each message you want to display.
3. In **Categories**, select the ticket categories where the message should appear. Leave the field empty to show the message in all categories. Select subcategories explicitly to include them.
4. Enter an optional **Heading** and use the **Message** editor to add text, links, or other formatted content.
5. Enable and save the plugin. Open a ticket in one of the selected categories and check the sidebar. If several messages apply to the same ticket, they all appear.

Write messages for everyone who can view the ticket, including customers.
