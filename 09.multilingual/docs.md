Set up your site’s languages and menus in Joomla first. Then translate the Helpdesk Pro content and interface your customers will use.

## Translate Support Content

Open each item in the Joomla administrator area and use its **Translation** tab to enter the text for your additional languages.

| Helpdesk Pro screen | What to translate |
| --- | --- |
| [Categories](/setup/categories) | Category titles, aliases, and descriptions. |
| [Emails & Messages](/setup/email-messages) | Notification subjects and bodies. Keep the bracketed tags unchanged so Helpdesk Pro can replace them with ticket details. |
| [Custom Fields](/setup/custom-fields) | Labels, descriptions, and choice text where applicable. |
| [Ticket Statuses](/setup/ticket-statuses) and [Ticket Priorities](/setup/ticket-priority) | The names that customers and the support team see on tickets. |
| [Knowledge Base](/knowledge-base) | Article titles, aliases, and content. |

## Translate the Interface and Check Each Language

Use **Helpdesk Pro → Translation** for built-in interface text, such as buttons and messages. Edit menu titles and any menu-specific intro text in Joomla’s menu items.

Switch to each language on the site and open the ticket form. Submit a test request, check the language of its confirmation email, and open any knowledge base links you published for that language.
