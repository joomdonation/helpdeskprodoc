# Plugins

Helpdesk Pro bundles plugins for ticket tools, Joomla integrations, and automation. Enable the ones your support workflow needs.

Most plugins are optional. Pages for features that are set up elsewhere, such as Pre-defined Replies, Email Ticketing and Scheduled Tasks, are linked from the table below.

To enable or configure a plugin, go to **System → Manage → Plugins** in the Joomla administrator area and search for its name.

| Plugin | When to use it |
| --- | --- |
| [Assign Ticket](/plugins/assign-ticket) | Give administrators and category managers a way to hand off tickets to individual staff members. |
| [Attachments](/plugins/attachments) | Give ticket viewers one place to find files attached to the ticket and its replies. |
| [Pre-defined Replies](/setup/pre-defined-replies#use-a-saved-reply) | Let your support team insert saved answers into ticket comments. |
| [Ticket History](/plugins/tickets-history) | Look up previous requests associated with the current ticket’s customer. |
| [Content - Helpdesk Pro](/plugins/content-helpdesk-pro) | Add the ticket submission form to an existing Joomla article. |
| [Auto Close Tickets](/scheduled-tasks/auto-close-tickets) | Close tickets after a period of inactivity (a scheduled task; also covers the older system plugin). |
| [Custom Messages](/plugins/custom-messages) | Show help links, notices, or instructions alongside tickets in selected categories. |
| [System - Helpdeskpro Reply Via Email](/create-and-reply-tickets-via-email) | Read incoming support email from an IMAP mailbox and use it to create tickets or add replies. |
| [Task - Helpdesk Pro](/scheduled-tasks) | Close inactive tickets and clean up old attachments, sensitive data, or whole tickets through Joomla's Task Scheduler. |
| [Smart Search - Helpdesk Pro Knowledge Base](/knowledge-base#include-articles-in-joomla-smart-search) | Include Helpdesk Pro articles in Joomla’s site-wide search. |
| [Installer - Helpdesk Pro](/getting-started/installation#update-from-joomla) | Receive extension updates through Joomla using a Download ID. |
| [User - Helpdesk Pro](/plugins/user-helpdesk-pro) | Keep ticket email addresses in sync when customers change their Joomla account email. |
